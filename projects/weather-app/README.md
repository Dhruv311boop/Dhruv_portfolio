# Weather App

A sleek weather application built with vanilla HTML, Tailwind CSS, and the OpenWeatherMap API.

## Features
- Search weather by city name
- Use current GPS location
- Real-time temperature, humidity, wind speed, feels like
- Sunrise / sunset times, visibility, pressure
- Beautiful glassmorphism UI

## Setup
1. Get a free API key from https://openweathermap.org/api
2. Open `index.html` and replace `YOUR_OPENWEATHERMAP_API_KEY` with your key
3. Open `index.html` in a browser — no build step needed!

## Deploy
- Drag and drop the folder to https://netlify.com (free)
- Or push to GitHub and enable GitHub Pages

## Stack
- HTML5, Tailwind CSS (CDN), Vanilla JavaScript
- OpenWeatherMap API (free tier)
